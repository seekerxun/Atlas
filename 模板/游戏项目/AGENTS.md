# 工作协议

本文件只负责导航，规则按需读。`atlas` 命令通过 `python3 {{atlas}}` 执行。

1. 开工先跑 `atlas route <路线名>`，**只读它列出的文件**，不要遍历目录。路线列表：`atlas route --list`
2. 没有对应路线，用 `atlas find <关键词>`，不要 grep 全仓。`创意/`、`产出/` 默认不读。
3. 新建 md 带 frontmatter：`类型`、`状态`，再写一行 `摘要:`。库和分组由目录推导，不用写。
4. 内容条目文件名 = 编号 + 名称（`NPC-W001-001 灰烬修女.md`），编号不写进 frontmatter。
5. `机制:` 只能填 `策划/机制/机制目录.md` 里已有的名字；需要新机制，先去那里加占位。
6. 关系只在**更具体的一方**声明一次（NPC 声明所属势力，势力不反列 NPC）。
7. 工具在使用它的文档 `工具:` 里登记；资产挂到对应条目 `资产:` 下；成批数值写进 `内容/表/` 的 csv。
8. **不知道放哪，就丢 `产出/`。** 一个概念全库只用一个名字；没讨论清楚的标草案。
9. 收工跑 `atlas check`，有错误不算完成。
