# 内容库说明

```
内容/
  _公共/            跨分组的实体（力量体系、谱痕、通用技能）
  _模板/            各类型的字段模板
  表/               CSV 数据表 + 同名说明 md
  W-001-断武之境/
    世界.md         这个分组的根节点
    NPC/ 势力/ 副本/ 剧情/ 道具/
  W-002-.../
```

分组维度在 `项目.yml` 的 `主分组` 里声明，这里是"世界"。

**为什么分组优先、不按类型优先：**做一个世界是一次完整的工作，文件集中在一处，AI 的上下文天然被圈住；一个世界可以整体新增、搁置、砍掉，不会在八个目录里留下碎片。类型那一维写在 frontmatter 里，画布照样能按类型聚合。目录留给日常导航，另一维交给程序。

## 什么进内容库

| | 放哪 |
|---|---|
| 有故事、有图、要反复引用的实体 | 内容库，一条一个 md |
| 装备、掉落、小兵这类成批数值条目 | `内容/表/` 的 csv，整张表当一个节点 |
| 还没立项的点子 | `创意/`，立项后再搬进来 |
| 长对话树、场景文本 | 该世界的 `剧情/` 下 |

按"有没有正文和图"分，不按数量分。

## 编号

文件名 = 编号 + 空格 + 名称：`NPC-W001-001 灰烬修女.md`，编号不写进 frontmatter。前缀词表见 `项目.yml`。

资产目录用同样的编号命名（`资产/W-001-断武之境/NPC-W001-001/`），程序靠它自动把图挂回条目。
