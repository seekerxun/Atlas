# 内容库说明

```
内容/
  _公共/            跨分组的条目
  _待定/            还没决定归哪个分组的条目，定了再搬
  _模板/            各类型的字段模板
  <分组名>/         按 项目.yml 的 主分组 建，比如一期视频、一个模块、一个课题
```

**为什么分组优先、不按类型优先：**一个分组是一次完整的工作，文件集中在一处，AI 的上下文天然被圈住；分组可以整体新增、搁置、砍掉。类型写在 frontmatter 里，画布照样能按类型聚合。

## 什么进内容库

| | 放哪 |
|---|---|
| 要反复引用、有正文或有图的东西 | 内容库，一条一个 md |
| 成批的表格数据 | CSV，表旁配一个同名说明 md |
| 还没立项的点子 | `创意/`，立项后再搬进来 |
| AI 刚生成、还没挑的 | `产出/` |
