# atlas 工具

还没写代码。这份文件是它的需求。

## 三条不能妥协的约束

1. **零安装依赖。** 不能因为 `pip install` 少了个包就跑不起来——AI 一报错就会退回去 grep 全仓，整套设计立刻失效。frontmatter 只用严格子集，自己解析，不依赖 PyYAML。
2. **全仓扫描。** 不是只扫 `工具/` 和 `资产/`。藏在 `策划/临时/草稿/` 里的脚本和图必须被发现并报"放错位置"——那正是这套东西要解决的核心问题。
3. **写回只碰 frontmatter。** 画布和迁移命令都只改 frontmatter 区块里的指定字段，不碰正文；写之前比对文件修改时间，不一致就中止。

## 命令

| 命令 | 作用 |
|---|---|
| `atlas 新建 <模板> <路径>` | 从 `模板/` 生成项目骨架，登记进注册表 |
| `atlas 扫描` | 写出 `.atlas/索引.json` |
| `atlas 检查` | 体检，有错误退出码 1（给 pre-commit 用） |
| `atlas 路线 --列表` | 列出所有路线 |
| `atlas 路线 <名字>` | **给 AI 用**：输出这条路线的文件清单和总行数 |
| `atlas 找 <关键词>` | 搜条目/工具/资产，并说明工具的服务对象 |
| `atlas 迁移 --加字段 / --改名 / --演习` | 批量改 frontmatter |
| `atlas 认领 <文件> <条目>` | 把资产或工具挂到某个条目上 |
| `atlas serve` | 起本地画布（只绑 127.0.0.1） |
| `atlas 钩子` | 安装 git pre-commit |

工具要能在项目任意子目录下跑，自动往上找 `项目.yml`。

## 扫描要做的事

1. 走全仓，按 `项目.yml` 的忽略列表跳过
2. 解析每个 md 的 frontmatter，按目录推导 `库` 和 `分组`
3. 把所有文件按规则归类：文档 / 工具 / 资产 / 表 / **未归类**
4. 建反向关系（谁引用了我、我出现在哪些路线里）
5. 资产目录名按编号正则自动挂回条目
6. 正文里的 `[[双链]]` 抽成软引用（不画线，只在卡片里列出）
7. 写 `.atlas/索引.json`

## 校验规则

见 [词表.yml](../规范/词表.yml) 的 `校验` 段。要点：

- **E05 机制名校验**：`机制:` 的值必须是项目 `机制权威` 文档里的标题。这条把"同一个概念全库同一个名字"变成程序执行。
- **W02 孤儿工具 / W04 放错位置 / W05 未归类文件**：这三条是"AI 到处乱丢东西"的直接证据，优先看它们。
- 体检结果不要只给一个总分。**分数会骗人**——一个故意做乱的样例项目也能拿 77 分。直接报三个数：未归类文件数、孤儿工具数、缺 frontmatter 数。

## 真实数据撞出来的五个细节

用无常乐园头两批文件验规范时发现的，写代码时别踩：

1. **豁免文件仍然可以被路线引用。** `AGENTS.md` 不要求 frontmatter、不算条目，但路线的 `docs` 里写 `AGENTS` 是合法的。校验时按"文件存在"判断，不要按"是不是条目"判断。
2. **机制名从表格首列读，不要从标题读。** 机制权威文档里混着"通用判定""机制索引"这类分节标题，按标题抽会把它们当成合法机制名，E05 就成了假校验。项目在 `项目.yml` 里用 `机制名来源: {段落, 取法}` 声明从哪取。
3. **列表值要按逗号切，不要用正则 findall。** `机制: [A, B, C]` 用 `[\[,]...[\],]` 这类正则匹配会吃掉分隔符导致跳项——B 会被静默漏掉。这类 bug 的后果是**校验假装通过**，比报错危险得多。
4. **YAML 写法必须收紧成一种，这是假校验的最大来源。** 同一个 `资产:` 字段，行内列表能校验、`-` 多行列表悄悄跳过，结果是"改成不存在的图也不报错"。规范已经收紧成"列表一律行内、嵌套最多一层"，解析器遇到别的写法**直接报 E10，不要宽容处理**。三次假校验全出自这一类，写代码时优先保证：**宁可误报，不可漏报。**
5. **分组未定的条目要有地方放。** 灰烬修女属于哪个世界还没定，既不是公共内容也不属于任何世界。约定放 `内容/_待定/`，定了再搬。`_待定/` 不判孤儿，但在画布上单列一块，提醒你还欠着决定。

AI 拿到的是清单，不是语料。

## 画布

见 [视图规范](../规范/视图规范.md)。做的顺序：**先校验和索引，再路线图，最后库视图。**数据干净之前画出来还是毛线球。

## 这套东西真正的失败模式

不是设计不好，是**没人写 frontmatter**。所以 `atlas 钩子` 比上面所有功能加起来都重要——缺 frontmatter 直接挡住提交。
