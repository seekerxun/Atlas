# 主题制作规范

**核心负责能做什么，主题负责怎么呈现。** 本规范适用于所有主题；现有主题的尺寸和布局只是各自的设计方案，不是功能约束。

## 核心保留

- 全屏画布，以及拖动、缩放、回全局和定位条目的能力。
- 路线、策划、内容、创意、资产五个导航及其作用。切换导航保留当前缩放和画布位置。
- 卡片展开阅读时，其余界面都在它后面且不接收鼠标，点别处即收卡；层级由核心与 `基础.css` 统一负责，主题的固定界面层级须低于 60。
- 条目与步骤的查看、展开、关闭、正文阅读、属性、关联、原文及资产入口。
- 重新扫描的进行状态由核心统一标记（`#刷[data-扫描中]`），各入口一致；主题只决定怎么表现。
- 搜索、重新扫描、检查详情、文件选择与预览、未认领及认领功能。主题选择入口统一紧接搜索框，随后是重新扫描；所有主题的入口都是一枚小图标按钮（`基础.css` 强制），不显示成文字下拉框；入口支持固定方案和跟随系统深浅，下拉内容由核心生成。
- 卡片的鼠标悬停关联由核心在连续悬停 250ms 后触发；移出、按下、拖动、收卡及重绘取消等待，键盘聚焦保留即时反馈。主题不得自行控制触发时机。
- 路线和步骤的增删改、关联文件、流程连线、撤销与重做。输入与确认使用页内询问框，不用浏览器弹窗。
- 步骤标题直接编辑；「加一步」创建默认步骤，不弹框询问名称。
- 数据读取和写回的含义、修改时间冲突校验、真实项目数据及已保存布局。
- 主题切换（包括跟随系统时的自动切换和同一主题内的深浅切换）不能重置视图、缩放、位置、输入或阅读状态，不能写入业务文件。

## 主题决定

字体、字号、颜色、材质、图标、边框、装饰、间距、控件位置、卡片尺寸、面板尺寸、排版、响应式规则、语义缩放表现及动画均由主题决定。

导航可以放在顶部或侧面，阅读可以用居中卡片或侧边面板。主题可以调整 DOM 的排列、使用不同模板和动画，不限于换色或修改 CSS。

类型应能辨认，现有类型颜色可以重新设计。关联与流程的含义由核心保留，如何高亮和绘制由主题设计。

字体过大或排版拥挤属于主题质量问题，不作为核心尺寸限制。但主题不能漏掉功能、让操作入口不可达、覆盖用户数据，或把画布缩成导航旁边的一块区域。导航等界面应覆盖在全屏画布之上。

## 实现边界

- `视图/核心.js` 共用功能、状态和写回；不要为每个主题复制一份核心。
- `视图/基础.css` 保留全屏画布与坐标、输入交互及搜索后主题入口的共同位置，不规定卡片尺寸。
- `视图/主题/<id>/样式.css` 控制外观、字体、尺寸、位置与响应式样式。
- `视图/主题/<id>/主题.js` 默认导出主题创建函数，提供布局计算、模板、阅读面板定位和视觉动效。接入方式见 `视图/说明.md`，准确契约见 `视图/主题接口.md`。
- `视图/画布.html` 是功能节点和资源入口。主题可以调整呈现，但保留功能节点的 ID、动作、数据标识及可访问性。
- 通过区域模板重写呈现，保留功能连接点；状态类只表达状态，不规定效果。现有主题的装饰类和 CSS 选择器不是通用必选清单。
- 核心自己输出的 CSS 变量（`--线`、`--主`、`--好`）和它直接生成的类名同属功能连接点，主题必须定义，核心为变量写了中性兜底色、为详情连接点缺失写了提示，漏了不会崩，但会脱离主题配色；清单见 `视图/主题接口.md`。
- 几何尺寸通过主题布局接口与 CSS 协调，不用强制覆盖制造显示尺寸与拖动／连线计算不一致。现有模板边界不作为永久设计限制；不足时扩展共享接口。
- 新增主题只创建自己的目录，在 `视图/主题/目录.json` 登记并声明外观；不修改 HTML、共享核心和其他主题。
- 同时提供深浅两种外观的主题只建一个目录、登记 `["浅","深"]`，用 `html[data-外观]` 切换配色，不复制成两个主题。
- `视图/主题加载器.js` 统一处理切换和清理。模块顶层与创建函数只做定义；在装配钩子中使用提供的监听、动画、装饰等接口，其他副作用用 `api.清理()` 回收，避免影响下一主题。
- 保持本地运行、无安装依赖、无需打包。需要调整共享功能时，明确作为功能变更处理，并验证所有受影响主题。

## 验收

1. 先确认预览服务使用的是正确项目；在真实内容上检查主题，写盘测试使用临时项目。
2. 设置非默认缩放和平移，逐一切换五个导航，确认状态不变。
3. 验证阅读、关闭、搜索、预览、检查详情、步骤编辑、关联、认领和撤销等相关功能仍可用。
4. 检查桌面与窄屏、不同缩放、连续操作；尺寸可以不同，但内容应能阅读、入口应能操作，动画可中断并尊重减少动态效果。
5. 来回切换主题，确认旧样式、监听器、动画和装饰不残留，输入草稿与阅读位置保留；新主题加载失败时原主题仍可用。
6. 单纯展示主题不得修改业务内容或已保存布局。交付时说明视觉变化和实际验证结果。
