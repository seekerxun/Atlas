# 主题接口

本页定义接入方式，不规定视觉风格。功能边界见 `规范/主题制作规范.md`，现有主题（矢量、霓虹）仅作示例。主题作者不需要照抄它们的选择器。

## 文件和加载

- 必需 `主题/<id>/样式.css` 和 `主题/<id>/主题.js`；CSS 可以为空但不能缺失。每个登记的外观还要一张 `主题/<id>/图标-<外观>.svg`（如 `图标-浅.svg`、`图标-深.svg`），见《深浅外观》。脚本默认导出同步函数 `创建主题(api)`，返回下述主题对象。
- 可以相对导入自己目录内的模块，例如矢量的 `模板.js`。新增主题不得导入其他主题的源码作为依赖，否则那个主题改动会影响它；复制需要的参考代码到自己的目录。
- **改完 `主题.js` 必须刷新页面。** 服务端是 `Cache-Control: no-store`，但 `import()` 的模块已经缓存在当前页面里，来回切主题执行的仍是旧脚本；CSS 每次都会重新加载，所以典型现象是「样式改动生效了、脚本改动没生效」，别误判成自己写错。
- `主题/目录.json` 格式：`{"默认":"矢量","主题":[{"id":"矢量","名称":"矢量","外观":["浅","深"]},{"id":"霓虹","名称":"霓虹","外观":"深"}]}`。id 唯一且对应目录，允许中文、字母、数字、下划线、短横线。显示名只取登记的 `名称`；主题对象不需要 `名称` 属性。`外观` 必填：`"浅"`、`"深"`，或深浅两用的 `["浅","深"]`；缺失或写错时加载器在启用前报错。
- 外观与跟随系统见下文《深浅外观》。
- 加载器同时等待 CSS 和 JS（包括它导入的模块），总等待上限 10 秒。失败保留当前主题；首次启动选中的主题失败时尝试默认主题。校验模板函数及布局参数后才启用；装配失败尝试恢复旧主题。
- 旧主题的 CSS 会移除，受管理的动画、计时器、监听器和装饰会回收。模块与创建函数只做定义，装配钩子才产生副作用；直接操作浏览器必须注册清理。这里不是脚本沙箱。

## api 成员

| 准确名称 / 签名 | 返回与用途 |
|---|---|
| `$(选择器)` | `document.querySelector` 的结果，可能为 null。 |
| `转义(值)` | HTML 文本／双引号属性转义字符串，不是 JavaScript 字符串转义。 |
| `图后缀` | 正则表达式；用 `图后缀.test(路径)` 判断图片扩展名。 |
| `可动()` | 布尔值；用户要求减少动态效果时为 false。 |
| `分组数据()` | 当前库 `{分组名: 条目数组}`。 |
| `更新关联()` | 按核心已确认的选择／悬停状态刷新关联高亮，无返回值；不会提前触发尚在等待的悬停。 |
| `视图规则(视图名)` | `"流程"`（路线）／`"文档"`／`"草稿"`／`"素材"`；不认识的名字返回空串。 |
| `视图原型(视图名)` | 五个原型之一：`路线 策划 内容 创意 资产`。默认名字且规则没改的标签返回自己；其余按规则取代表（文档→内容，草稿→创意，素材→资产）。主题的图标、配色、背景按原型准备，不要按导航名写死。 |
| `读取状态()` | `{数据,视图,缩,位:{x,y},布局,展开卡,外观}`；展开卡是 DOM 或 null，布局是已保存位置字典，外观是当前的 `"浅"` 或 `"深"`。只读使用；除位以外的对象不保证是副本。 |
| `监听(target,type,fn,options)` | 注册监听，返回解除函数；卸载也自动解除。 |
| `延时(fn,ms)` / `循环(fn,ms)` | 返回浏览器计时器 ID；卸载停止。 |
| `动画(el,frames,options)` | 返回 Web Animations 的 Animation；卸载取消，包括保留终态的动画。 |
| `装饰(el,parent=document.body)` | 插入额外节点，返回 el；卸载移除。 |
| `移动(el,parent,before=null)` | 移动功能节点；卸载恢复原父节点和顺序。 |
| `样式(el,values)` | values 如 `{'font-size':'16px'}`，使用 CSS 属性名；卸载恢复。 |
| `类名(el,name,enabled=true)` | 设置类名状态；卸载恢复。 |
| `清理(fn)` | 登记额外清理回调并返回它；卸载按登记的逆序执行。 |

**导航是项目配置出来的。** 视图名单 = `路线` + 项目 `项目.yml` 里声明的标签（见 `规范/目录规范.md`《标签》），数量和名字都可能不同于默认五个，某种规则也可能一个标签都没有。标签名来自项目文件，插进 HTML 时要 `转义`。

**资产卡。** 素材规则视图里的卡由服务端为该标签目录（默认 `资产/`）下每个文件生成，结构与条目相同：`库` 为标签名（默认「资产」），`分组` 为所在目录（如 `S-001-二次函数 / E-S001-01`），`类型` 为「图片／视频／音频／网页／文件」，`摘要` 写挂在哪些条目，`资产展开` 只含它自己，`被引用` 为挂载它的条目路径，`行数` 为 null，另有 `资产文件: true`。点开时核心在 `#原` 里内嵌图片、视频、音频或网页预览，不读取正文；主题照常渲染，无需特殊处理。

项目条目 `n` 常用字段：`路径、标题、名称、类型、库、分组、摘要、状态、编号、行数、标签、关联、被引用、软引用、资产展开、工具、路线`。可选字段可能为空；不要修改条目对象。路线 `r` 包含 `名称、说明、入口、步骤`；步骤 `s` 包含 `id、title、note、docs、tools、outputs、next`，其中列表可能缺省。

## 布局和坐标

世界坐标是画布未缩放时的 CSS px，可以为负；屏幕位置约为 `世界坐标 × 缩 + 位`。盒内坐标相对分组盒，核心再加 `内左/内顶`。屏幕空间（阅读区域、动画原框）不要再次乘缩放。

`主题.布局` 当前要求以下 11 个键全部存在，为有限非负数；卡宽、卡高必须大于零。**这些是主题给出的值，没有规定任何主题的数值。**

| 键 | 含义与基准 |
|---|---|
| `卡宽` | 库条目卡的未展开宽度；核心写入卡片行内 width，并用于定位条目。 |
| `卡高` | 主题布局计算用的基础高度；每张库卡实际高度取布局结果的 `c.h`。 |
| `隙` | 主题布局计算用的卡片间距；核心不会自动替主题排列。 |
| `盒隙` | 主题布局计算用的分组间距；核心不会自动增加此间距。 |
| `内左` | 盒内每张卡／类型标签的 x 坐标附加量，相对盒的定位原点。 |
| `内顶` | 盒内每张卡／类型标签的 y 坐标附加量，相对盒的定位原点。 |
| `路线起点` | 第一条路线传入布局函数的初始基 y，世界坐标。 |
| `路线间距` | 下一路线基 y 为本路线各 `y+h` 与当前基 y 的最大值，再加此值。 |
| `路线标题距` | 路线标题 top 为最上步骤 y 减此值；全局取景也预留该距离。 |
| `路线编辑距` | 路线工具栏 top 为最上步骤 y 减此值；不是距标题的距离。 |
| `连线出口` | 连线起点 x 相对步骤左边的偏移；y 取步骤实际高度中点。应与步骤宽度／连线柄位置一致。 |

卡高、隙、盒隙属于现有接口的布局约定，目前核心只保存它们，计算由主题负责。未来可简化接口，不能据此规定所有主题采用相同网格。

`算库布局()` 返回数组：

```js
[{id, 名, 数, x, y, w, h, 卡们: [
  {类标: '技能', x, y},          // 类型标签，无需 h
  {节: n, x, y, h}              // 条目卡，宽取布局.卡宽
]}]
```

盒的 `x/y/w/h` 是世界坐标／尺寸；卡们的 `x/y` 是盒内坐标，尚未加内左/内顶。`节` 必须对应真实条目，不能造假路径。id 是稳定布局键，格式见下文《布局键是共享命名空间》。尺寸须有效，盒应容纳内容。读取 `读取状态().布局[id]` 的 `{x,y}`，不要在呈现时写回。

`算路线布局(r,基y)` 返回与 `r.步骤` **同长度、同顺序**的 `[{id,x,y,h}]`。`x/y` 为世界坐标，h 是布局占位高度；实际步骤高度和宽度由主题 CSS 决定，须与占位及连线出口协调。id 稳定，格式见下文《布局键是共享命名空间》；空路线返回 `[]`。

**布局键是共享命名空间。** `.atlas/布局.json` 由所有主题共用，核心每次整份写回，键完全来自上面两个函数返回的 `id`。**新主题应沿用同一套格式**：库用 `盒:<视图>:<分组名>`，路线用 `步:<路线名>:<步骤id>`。这样用户在任一主题里拖过的位置，在别的主题里同样生效。换一套键不会损坏文件，但位置不互通，两套键会一起堆在里面；最糟的是沿用同样的格式却换了含义——那会直接继承另一个主题的坐标。需要主题专属的排布时，换布局算法，不要换键。

**整条路线的平移由核心负责。** 拖动 `.路线标题` 会移动整条路线，核心把平移量存成 `路线:<路线名>` → `{x,y}`。`算路线布局()` 读到的步骤位置和返回的位置都是平移前的坐标，核心拿到结果后再整体加上平移量，写行内样式和画连线；拖单个步骤时核心也先扣掉平移量再存 `步:` 键。主题不读这个键，也不要自己再加一次平移；下一条路线的 `基y` 仍按平移前的位置计算。核心为 `.路线标题` 和 `.编辑条` 带上 `data-路线`。

库卡 `left/top/width/height`、分组盒几何位置和步骤 `left/top` 由核心写成行内样式，数值来自主题布局结果。常规布局通过这些接口调整；不要仅用 `!important` 改显示尺寸而让布局和连线仍按旧尺寸计算。展开时的尺寸、位置和响应式由 `定位展开()` 与主题 CSS 共同控制。

## 主题对象的方法

除注明可选外，以下方法必须存在。纯模板／布局函数不能修改核心数据或触发写盘。

| 签名 | 返回及调用时机 |
|---|---|
| `色(类型)` | CSS 颜色字符串，可以是主题自定义变量；未知类型也要有结果。 |
| `导航内容(视图们)` | HTML 字符串；视图们是视图名数组（见上文「导航是项目配置出来的」）。创建导航时调用，保留每个视图的按钮和计数连接点。图标用 `视图原型(v)` 取，取不到时也要能显示。 |
| `定位导航()` | 无返回要求；导航选中态或窗口变化后更新外观。 |
| `算库布局()` / `算路线布局(r,基y)` | 返回上节的布局结果。 |
| 可选 `算自动布局({折叠们})` | 用户点「排列」时调用，返回当前库的分组布局数组，至少含 `id,x,y,w,h,排列`；`折叠们` 是已折叠布局键的 Set 副本。核心验证尺寸、保存坐标和 `排列`，作为一笔可撤销的布局操作；纯计算，不自行写盘。未接入主题及路线视图隐藏入口。 |
| 可选 `分组折叠高(外观)` | 返回折叠后分组盒的高度（世界 CSS px）；有限正数表示当前外观支持折叠，缺省／0 表示不启用。模板同时提供 `button[data-分组开合]`；核心设置行内高度、隐藏内容和开合状态。 |
| `卡html(n)` | 库卡的内部 HTML，不含核心创建的 `.卡` 外壳。 |
| 可选辅助 `行(…)`、`详情头(…)` | 现有主题的模板内部复用的方法，签名由主题自定；核心不调用，其他主题不必提供，也不要求 `.行`。 |
| `阅读区域()` | `{顶,底,高}`，单位屏幕 CSS px；顶／底是相对 `#台` 顶边／底边的留白，高为可阅读高度。用于定位条目与全局取景。 |
| `初始视野()` | `{缩,位:{x,y}}` 或 undefined；缩是正数，位是屏幕 px。仅首次数据呈现应用，导航和主题切换不重置视野。 |
| `缩放外观(缩)` | 无返回要求；缩放更新时调整信息密度和状态类。 |
| `定位展开()` | 无返回要求；读取展开卡与画布状态，定位、设置阅读尺寸；不可改变核心缩放／位置。 |
| `定位文件预览()` | 无返回要求；打开预览、切换主题、窗口变化时定位。 |
| `卡片过渡(card,原框)` | 无返回要求；展开／收起后调用。原框为变化前的屏幕 DOMRect，也可能缺省；新位置从 card 读取，`.展开` 表示展开方向。 |
| `停卡片动效(card)` | 同步停止该卡片的主题动画；card 可能为 null。 |
| `布置阅读幕()` | 更新阅读遮罩；展开卡为 null 时撤除。 |
| `画布入场()` | 导航变更绘制后调用，纯视觉动画。 |
| `镜头缓动(t)` | t 为 0–1 进度，返回有限的缓动进度；与正数 `镜头时长`（ms）共同定义主动取景动画。 |
| 可选 `装配界面()` | 启用主题后调用，重排固定界面、注册视觉资源。 |
| 可选 `装配画布()` | 每次画布重绘后调用；不可累积旧装饰／监听。 |
| 可选 `装配详情(panel)` | 详情插入后调用，可重新排列内部功能节点。 |
| 可选 `卸载()` | 回收自行管理的视觉资源；不能清除用户状态。 |
| 可选 `外观变化(外观,旧外观)` | 深浅两用主题在同一主题内切换外观时调用；此时 `html[data-外观]` 已更新，主题不重新加载。只做视觉过渡，不要重画核心区域。 |

**分组折叠。** 可选接入，不要求其他主题新增按钮。核心给 `[data-分组开合]` 绑定点击和原生键盘操作，同步 `aria-expanded`、名称和提示；当前外观不支持时隐藏按钮并展示完整分组。折叠时盒带 `data-折叠`，直系卡片和类型标签设为 `hidden`、`inert` 及行内 `display:none`，分组宽度、坐标和其他分组位置不变，展开恢复布局原高。主题的折叠高度须容纳标题与按钮在各缩放级别的尺寸。状态按项目保存在浏览器 `atlas:分组折叠:<项目根>`（已折叠的稳定布局键数组），不写业务文件或 `.atlas/布局.json`；重绘、刷新和主题切换保留。定位或阅读隐藏条目时核心先展开所属分组。矢量目前仅浅色外观接入，高度为 84px；深色及未接入主题显示完整分组，切回浅色恢复记忆。

**自动排列。** 入口 `#角 #自动排列` 位于「全局」左边，只整理当前库。当前矢量主题接入：按现有目录／系列分组，组内按 `修改时间`（Unix 秒）降序，时间相同按编号／名称自然序；组间取组内最新时间优先放置，允许小组填空，因此整体阅读顺序不保证严格时间递减。少量条目优先一行，其余按尺寸选择列数、倾向两三行；条目特别多时继续增加行数，不隐藏内容。外层采用不旋转的空闲矩形切分，保持组完整、统一间距，按实际折叠高度占位。展开折叠组不移动邻居，需要时再次点排列。

服务端 `/数据` 给每个文档与资产条目增加 `修改时间`，不可访问或扫描后消失时为 null，排序置后；旧服务缺该字段时入口禁用并提示重启。本次点击使用当前扫描快照。核心将组内方案保存到该分组的布局记录：`{x,y,排列:{版本:1,列,顺序:[条目路径,…]}}`。矢量的 `算库布局()` 根据保存的列数和顺序还原，新增条目接在末尾，更新修改时间不会自行重排。其他主题可忽略 `排列`，仍共享坐标；核心拖动保留记录中的扩展字段。排列成功才应用界面并入撤销栈，失败保留原布局，写入串行防止旧拖动保存覆盖新结果。整理后主动全局取景；切换导航和普通重绘仍保留视野。

## 深浅外观

**方案 = 主题 + 外观。** 只登记一种外观的主题只有一个方案；登记 `["浅","深"]` 的主题有两个方案，悬停提示里显示为「名称 · 浅」和「名称 · 深」。

- 核心在 `<html>` 上设置 `data-外观="浅|深"`，与 `data-theme` 同时更新。深浅两用主题在样式里用 `html[data-外观="深"]` 等选择器切换配色和 `color-scheme`，**不要为另一种外观再建一个主题目录**。单一外观的主题可以忽略这个属性。
- 同一主题只换外观时，核心不卸载、不重载主题，只改属性并调用可选的 `外观变化()`。因此颜色应写成 CSS 变量；JS 里需要颜色时在用到的那一刻从计算样式读取，不要在创建时缓存。
- 主题面板 `#主题面板` 由核心生成：顶部「固定 / 跟随系统」两个模式按钮，下面按浅色、深色两行排出各方案（跟随时两行分别是「白天用」「夜间用」），每个方案是一枚 `button.主题项`（`data-值`、`aria-pressed`），只显示图标，名字在悬停提示里。跟随系统时核心监听 `prefers-color-scheme`，回到窗口时再核对一次，按当前外观切换方案，切换同样保留视图、缩放、位置、阅读和输入状态。
- 用户的选择存于浏览器 `localStorage` 的 `atlas:主题选择`（`{模式,手动,浅,深}`，值为 `主题id@外观`）；旧版只存主题 id 的 `atlas:theme` 会被读取迁移。主题不要读写这个键。
- **方案图标**：`图标-<外观>.svg` 是这个方案的缩略画面，64×42 比例、自带配色，一眼能看出风格（矢量是大地色几何，霓虹是黑底描边发光，剪报是贴胶带的纸片和红虚线）；不要写字，也不要依赖 CSS 变量（它以 `<img>` 显示）。图标缺失时核心退回显示名字。
- 面板在浏览器顶层（popover），位置由核心贴着按钮计算，点别处或按 Esc 关闭。`基础.css` 给出结构和取自 `--面 --字 --字3 --边 --主` 的默认配色；主题可以为 `#主题面板`、`.主题模式 button`、`.主题组名`、`.主题项` 写底色、边框、圆角、阴影、字体和 `:popover-open` 开场动画，不改它的位置和图标尺寸。

## 区域模板

主题对象必须提供 `模板` 对象，包含下表的 11 个同步函数，均返回 HTML 字符串。矢量和霓虹把它们放在各自的 `模板.js`，其他主题可内联或自行拆文件。核心传入原始数据并在呈现后绑定功能；所有输入只读。`按路径` 是路径到条目的索引，`解析(引用)` 返回条目或 null，`路线文件(引用)` 返回文件候选或 undefined。

| `模板.方法(参数对象)` | 可自由设计的区域 / 要保留的入口 |
|---|---|
| `条目详情({n,按路径,解析})` | 完整详情内部：正文、属性、关联、资产、原文和路径操作。保留标题、关闭、阅读滚动容器和 `#原` 正文插槽；侧栏按下文《详情侧栏分区》给出 `[data-侧区]` 区块和 `[data-大纲]` 槽。核心负责读取和安全渲染正文。 |
| `步骤详情({r,s,路线名,步id,路线文件})` | 完整步骤详情内部：标题、护栏、文档、工具、产出、下一步、复制命令及编辑／删除入口。 |
| `步骤卡({s,i,路线文件})` | 步骤卡内部，i 从 0 起；保留标题 h4 和连线柄 `.柄`。 |
| `分组头({b})` | 分组盒内部标题，b 为库布局结果中的盒；名称、数量应可辨认。 |
| `路线标题({r})` | `.路线标题` 内部的名称、入口标记、说明。 |
| `路线工具({r})` | `.编辑条` 内部的加步骤、改名／说明、删路线及连线操作提示。 |
| `检查列表({发现,按路径})` | 发现数组每项有 `级别、码、信息、位置、提示`；可定位的条目保留 `button[data-发现="原数组索引"]`。 |
| `候选列表({命})` | 已筛选的文件候选数组；保留 `button[data-i="索引"]` 选择入口和 `data-预览="路径"` 预览入口。 |
| `未认领列表({组})` | `[[分组名,路径数组],…]`；文件入口保留 `.项[data-文件="路径"][draggable="true"]`。 |
| `搜索结果({前,总数,更多,提醒,标记,记录})` | `前` 为当前展示的 `{文,副,片段,…}`，首次 30 项，每次继续加载增加 30 项；必须显示 `总数`。结果入口保留 `[data-i="索引"]`、`tabindex="0"` 和 `role="button"`，由核心执行跳转；`更多` 时提供 `[data-搜索更多]` 按钮。`提醒` 非空时用纯文本显示全文缺失原因。`标记(文本)` 返回已转义并用 `<mark>` 标出关键词的 HTML，仅供标题、副文、片段使用，不再转义。`记录` 为数组时改画最近搜索（空数组显示暂无记录），文字须转义；记录用 `[data-搜索记录="索引"]` 按钮，清空用 `[data-清除搜索记录]` 按钮，行为由核心绑定。 |
| `项目列表({列表})` | 每项 `{路径,名称,类型,备注,当前,存在,端口,运行中}`；每个项目保留 `button[data-i="索引"]`，`存在` 为 false 时应 disabled。核心负责打开与切换。 |

列表顺序可以改变，但 data 索引须对应输入数组，不能把索引改成重排后的序号。模板插入外部文本必须转义，禁止把项目内容当可执行代码。动作继续调用核心：`收卡()`、`跳(路径,锚?)`（锚是标题文字，可省略）、`系统打开(路径)`（系统默认应用打开，失败时退回浏览器新标签）、`系统打开(路径,true)`（在访达中显示）、`去路线(名称)`、`抄(文本)`、`加步骤(路线名)`、`改路线头(路线名)`、`删路线(路线名)`、`编辑步骤标题(路线名,步id)`、`改步骤字段(路线名,步id,字段,提示文)`、`加步骤项(路线名,步id,字段)`、`删步骤项(路线名,步id,字段,值)`、`断线(路线名,从,到)`、`删步骤(路线名,步id)`。字段沿用 note/docs/tools/outputs；不要在主题重写保存。生成 onclick 时先 `JSON.stringify` 每个参数，再用 `转义` 处理整个属性值。

切换主题会重画这些区域并重绑动作，保留选中、输入和阅读状态。文件预览的正文／源码 DOM 保留，不重新请求。主题可以用装配钩子移动固定功能节点，但不能替换已绑定事件的节点。

## 功能连接点与样式覆盖

**功能连接点不是外观规定。** 下列是当前核心依赖，不能删除或重命名；只规定标识与必要的容器关系，不规定字体、颜色、大小、分栏。

| 范围 | 必须保留 |
|---|---|
| 画布 | `#台 > #世界`，世界内的 `#线`、`#阅读幕`；核心生成 `.盒[data-id]`、盒内 `.卡[data-路径]`、`.步[data-id][data-路线][data-步]`、`.类标`、`.编辑条`、`.空`。不要把坐标节点移出原坐标容器。 |
| 导航 | `#签` 内每个视图一个 `button[data-v]`，其内 `.导航计数`；其余图标与文字结构自由。核心在按钮上补 `data-规则` 和 `data-原型`，CSS 按原型配色时选 `[data-原型]`，不要选 `[data-v]`。 |
| 详情 | `#屉` 内一个标题 h3（核心赋 id=详情标题）、可聚焦的 `.收起` 关闭入口、`.详情体` 阅读滚动容器；条目详情还需 `#原`，侧栏分区用 `[data-侧区]`（内含 `.侧区头` 按钮和 `.侧区体`）与 `[data-大纲]`。核心把屉放进展开卡，主题装配只重排内部。 |
| 步骤 | `.步` 内 h4 标题与 `.柄` 连线入口；核心在 `.步` 上写 `data-标题`。标题编辑生成 `.步骤标题编辑` 下 form/input/提交和取消按钮，核心保留处理及草稿。 |
| 文件 | `[data-预览]` 为预览入口；`#挑` 内 input 与 `.单`；列表连接点见上表。 |
| 关联与线 | `[data-关联="路径"]` 用于悬停高亮，`[data-边]` 用于断开流程边。 |
| 固定控件 | HTML 中 `#顶 #项目 #导航 #名 #产出控件 #产出选择 #运行控件 #运行选择 #运行面板 #体检 #新路线 #搜 #搜果 #刷 #视图名 #视图数 #未 #未数 #未体 #角 #缩小 #放大 #缩 #撤销 #重做 #回 #主题控件 #主题选择 #提示`；搜索 input 留在搜内；`#主题控件` 留在 `#顶` 中紧接 `#搜`、位于 `#刷` 前，不由主题移走或固定到角落。`基础.css` 把它统一成小图标按钮：`#主题选择` 是透明铺满的按钮，点开同在 `#主题控件` 里的 `#主题面板`，图标画在 `#主题控件::before`（颜色取 currentColor）；主题只用 `--主题钮`（按钮边长，默认 40px）、`--主题图标`（图标边长，默认 18px）、`--主题图形`（可换图标的 mask 图）和按钮的底色、边框、圆角来设计，面板外观见《深浅外观》；`#运行控件` 留在 `#顶` 中紧接在 `#体检` 之前（见下文《运行入口》），`#产出控件` 紧接在 `#运行控件` 之前（见下文《产出入口》）。未认领开关保留 `#未 .头`。 |
| 启动 | `#启动状态 #重试启动` 和 body 的 `data-启动中`；主题还未加载时也要能显示失败和重试，不移动这些节点。 |
| 对话框 | `#文件预览 #文件预览标题 #文件预览路径 #文件预览正文 #关闭文件预览`；`#检查详情 #检查标题 #检查计数 #检查说明 #检查列表 #关闭检查`；询问框 `#询问 #询问表 #询问标题 #询问说明 #询问字段 #询问取消 #询问确定`；项目窗 `#项目窗 #项目窗标题 #项目列表 #关闭项目窗 #新建项目 #打开路径`；产出窗 `#产出窗 .产出窗头 #产出窗标题 #产出窗计数 #关闭产出窗 .产出窗正文 #产出批次 #产出批`。保留 dialog、ARIA 标题关系及关闭入口；内部可移动原节点。 |

详情模板缺少 `h3`、`.收起` 或 `.详情体` 时，核心提示作者并跳过对应处理，卡片仍能展开；缺 `#原` 时不读取正文。这是兜底，不是可以省略连接点。

鼠标在未展开卡片上连续悬停 250ms 后，核心才设置悬停关联状态；移出、按下、拖动、收卡与重绘取消等待，键盘聚焦即时生效。延迟与取消由核心统一负责，主题不得用自己的计时器或 CSS 延迟接管。

**询问框。** 核心所有需要输入或确认的地方（新路线、改路线名、删路线、删步骤、改 AI 护栏、加工具／产出、认领图片的分类）都用 `#询问`，不再调用浏览器的 `prompt` / `confirm`。核心每次打开时重写 `#询问标题`、`#询问说明`（没有说明时 `hidden`）和 `#询问字段`：每个字段是一个 `label.询问项`，内含说明文字 `span` 和一个 `input`；选择型字段（如新建项目的模板）是 `div.询问项[role=radiogroup]`，内含 `span` 和 `.询问选项`，后者每项是 `label > input[type=radio] + span`，`基础.css` 已把单选隐藏成可点的文字片，主题给 `.询问选项 span` 和 `input:checked + span` 定外观；字段为空时就是确认框，`#询问字段` 为空。危险操作（删除）时 `#询问` 带 `data-危险`。主题负责这些节点的全部外观，不要替换 `#询问表` 的提交与取消按钮。

**详情侧栏分区。** 条目详情的侧栏分成可开合的区，每区是一个带 `data-侧区="名"` 的元素，内含按钮 `.侧区头` 和内容 `.侧区体`；现有主题用四个区：`属性`（属性表、标签、调用机制、工具）、`标题`（正文标题大纲）、`被引`（被谁引用）、`引用`（frontmatter 关联、文中引用、出现在路线），复制路径等三个操作放在区外、贴侧栏底部。核心负责：
- 开合：带 `data-独立` 的区自己开合；其余区同一时间只展开一个，再点已展开的区则全部收起。展开的区带 `data-展开`，收起的区体设 `inert`（不可聚焦、读屏跳过），`.侧区头` 同步 `aria-expanded` 和 `aria-controls`。核心**不**给区体设 `hidden`：收起时怎么隐藏、要不要动画由主题 CSS 决定，最少也要写 `.侧区:not([data-展开])>.侧区体{display:none}`。
- 记忆：按项目存在浏览器 `localStorage` 的 `atlas:侧区:<项目根>`（`{独立:{名:布尔},展开:名|null}`），默认属性展开、标题展开。记住的区在这篇里没有时，临时展开第一个可见区，不改记忆。主题不要读写这个键。
- 标题大纲：正文渲染完后，核心把 `#原` 里的 h1–h4 填进 `[data-大纲]` 槽，每项是 `button.大纲项[data-级]`（级从 1 起，按本篇最浅一级算），和详情标题同名的开头大标题不收。点击在 `.详情体` 内滚到该标题；滚动时给当前所在标题的项加 `aria-current="true"`，并把它滚进所在 `.侧区体` 的可见范围。没有标题（包括资产卡）时核心给大纲所在的区设 `hidden`。
- 时机：模板插入后、卡片展开前就排好开合状态，打开卡片不会播开合动画；主题想做开合动画，在 `装配详情(panel)` 里监听 `.侧区头` 的点击（捕获阶段量旧高度，冒泡阶段量新高度再补间），矢量即这样实现。

侧栏固定、区内滚动是现有主题的排版：`.详情体` 设 `container-type:size`，侧栏 `position:sticky;top:0;height:100cqh`，展开的区可压缩、区体内部滚动，操作按钮 `margin-top:auto` 贴底。展开卡若是高度自适应的纵向 flex，Chrome 会把侧栏的 `cqh` 算成 0，展开时改用块布局（霓虹的做法）。窄屏改回静态单列。

**退场动画。** `#检查详情`、`#文件预览`、`#询问` 关闭前，以及 `#挑`（文件挑选）、`#未`（未认领抽屉）收起前，核心先给元素加 `data-关闭中`，等元素或其子孙上由它触发的 CSS 动画或过渡播完（最长 600ms）再真正关闭或移除 `.开`。主题想要退场动画，就为 `[data-关闭中]` 写 animation / transition；不写就立即关闭。重新打开时核心会先清掉这个属性。用户开启减少动态效果时不等待。

**扫描状态。** 核心每次向 `/数据` 取数都是服务端的一次重新扫描，不论入口是 `#刷`、写回后的刷新还是窗口切回前台时的自动扫描（阅读、输入、对话框进行中跳过；结果没变不重画）；扫描期间核心给 `#刷` 加 `data-扫描中`，结束（包括失败）后移除。扫描可能快到同一帧里加上又去掉，想播完整动画的主题应监听属性曾被加上（例如 MutationObserver 的 `oldValue === null`），不要只读当前状态。主题可以替换 `#刷` 的图标内容，但保留 ID、`aria-label` 和点击动作，卸载时恢复。

**打开与新建项目。** 顶栏 `.品牌` 整块可点击，统一调用原生按钮 `#项目`（内含 `#名`）打开 `#项目窗`；独立按钮 `#项目位置` 只负责访达，不触发项目窗。一个 `atlas serve` 只管启动时所在的项目；每个项目的画布端口写在它自己的 `.devdock.json`（与 DevDock 同一份配置，没有就分配一个未被占用的端口写进去）。打开或新建别的项目时，服务端保证那个项目的画布在它的端口上运行（已在运行就复用），核心在新标签页打开它，当前页面不动；新标签被拦时改为询问是否在当前页打开。核心的写请求都带 `X-Atlas-Root`，服务管的不是这个项目时拒收。主题只负责 `#项目窗` 和 `项目列表` 的呈现。

**运行入口。** `#运行控件` 是当前项目 `.devdock.json` 里运行目标的入口，紧挨在 `#体检` 左边，结构和 `#主题控件` 一样：透明按钮 `#运行选择` 铺满，点开同在控件里的 popover `#运行面板`，面板内容和位置由核心生成。`基础.css` 把它做成和主题选择同尺寸的小图标按钮（取 `--主题钮`、`--主题图标`），并给它 `margin-left:auto`、取消紧随其后的 `#体检` 的 `margin-left`，所以平时它和检查一起靠右；主题在窄屏用 grid 排顶栏时要给它一个格子（现有主题放在第一行、检查左边那格）。图标是 `--运行图形`，不随主题的 `--主题图形` 变。除当前画布外有目标在运行时，核心给 `#运行控件` 加 `data-运行中`，`基础.css` 在右上角亮一个点，颜色取 `--运行色`。面板结构：`.运行头`（标题和 `.devdock.json` 字样）、`.运行列表` 下每个目标一个 `li.运行项`（运行中带 `data-运行中`，请求中带 `aria-busy`），内含 `.运行灯`、`.运行名 > b + small`、`.运行钮` 里 `button[data-动作="启动|停止|打开"][data-i]`，当前画布那一项不给停，显示 `.运行本页`；没有目标时是 `p.运行空`，出错时末尾一行 `p.运行错`（颜色取 `--运行错色`）。主题给 `#运行控件` 和 `#主题控件` 一样的底色、边框、圆角，给 `#运行面板` 和 `#主题面板` 一样的面板外观，可以改 `.运行项`、`.运行钮 button` 的圆角、边框和字体，并按自己的配色设 `--运行色` / `--运行错色`；不改结构和位置。

**项目名称与空间。** `.品牌` 是项目标识容器；`#项目名称行` 内有打开项目窗的 `#项目`（包含 `#名`）、只读 `#项目空间` 和独立的 `#项目位置` 按钮（在访达中直接打开当前项目根目录）。不要在按钮里嵌套另一个按钮。核心将标志、副标题、空间数字和留白的点击转发到 `#项目`，按钮自身不重复触发；键盘仍使用两个原生按钮，聚焦项目按钮时整块品牌显示焦点框。主题为整块品牌提供不透明底色，悬停也不能透出画布文字。核心更新空间文本、悬停时间和 `data-扫描中`，只更新这几个节点，不重画画布。`基础.css` 提供同行排列与小图标尺寸，配色取主题的 `--字/--字3`；主题可调整外观，须保留入口与功能 ID。大小按 1024 进位显示整数 M/G/T，小于 1M 的非零占用显示 1M；首次统计显示 `…`，失败且无缓存显示 `—`。

**产出入口。** `#产出控件` 是 `产出/` 的审阅入口，紧挨在 `#运行控件` 左边，结构和 `#运行控件` 一样：透明按钮 `#产出选择` 铺满，图标是 `--产出图形`。`基础.css` 把它做成同尺寸的小图标按钮，并把 `margin-left:auto` 从运行入口移到它身上，所以平时产出、运行、检查一起靠右；窄屏用 grid 排顶栏时要给它一个格子（现有主题放在运行入口左边那格，手机宽度第二行的搜索框跨两列让出位置）。有批次在上次打开之后改动过时，核心给 `#产出控件` 写 `data-新="批数"`，`基础.css` 在右上角画一个带数字的小圆，颜色取 `--产出新色`（默认 `--主`）。主题把它和 `#主题控件`、`#运行控件` 写在同一组选择器里即可。

**产出窗。** 点 `#产出选择` 打开模态 `#产出窗`，内容由核心生成：头部 `.产出窗头`（`#产出窗标题`、`#产出窗计数`、`#关闭产出窗`），正文 `.产出窗正文` 左边 `#产出批次`（每批一个 `button.产出批次项[data-批]`，当前批带 `aria-current`，过期批带 `data-过期`，新文件数是 `.产出新`），右边 `#产出批`：`.产出批头`、`.产出说明们`（每篇说明一个 `details.产出说明`，内含 `.正文`，提到的文件名是 `button.产出链`）、`.产出筛`（类型片 `button[data-产出种][aria-pressed]`，复选框 `input[data-产出筛]`）、按子目录的 `details.产出组`，组里 `.产出墙` 排 `.产出件`（`data-新`、`data-标记="通过|打回"`、正在预览的带 `data-当前`；内含 `.产出缩略`、`.产出件名`、`.产出件钮`）。点开文件复用 `#文件预览`，打开期间 ← → 翻看。`基础.css` 给出全部内部结构和取自 `--底 --面 --字 --字2 --字3 --边 --主 --好 --错` 的默认配色；主题把 `#产出窗` 加进自己 `#项目窗` 的外框、背景幕、开合与退场动画选择器，把 `.产出窗头`、`#产出窗标题`、`#关闭产出窗` 加进对应的头部选择器，就和其他对话框一致。主题可以再细调 `.产出件`、`.产出批次项` 等的圆角、边框和字体，不替换节点、不改 data 属性。

**阅读层级。** 卡片展开期间核心给 body 加 `data-阅读中`，收卡时移除。`基础.css` 据此把 `#台` 提到 `z-index:60`，并让 `#世界` 里除展开卡以外的节点都不接收鼠标；点在别处落到 `#台` 上由核心收卡，拖动平移和滚轮缩放停用。因此主题的固定界面（`#顶`、`#未`、`#角` 及同类装饰）要低于 60，阅读时它们才会压在展开卡和阅读幕之后；需要盖在阅读之上的（`#提示`、`#挑`、展开／收起的过渡装饰）要高于 60。对话框在浏览器顶层，不受影响。

核心设置的状态：`.展开`（卡片阅读）、`.选`（选中）、`.邻`（关联）、`.暗`（非关联）、`.悬`（悬停）、`.开`（导航选中／面板打开）、`.拖`（画布拖动）、`.靶`（连线目标）、`.可放`（可连接／可认领）、`.聚起`（包含展开卡的盒）、`.切入`（视图变更）。主题决定每个状态的外观；打开／关闭和可交互状态必须正确体现。核心另设置 `data-状态`、ARIA、hidden、disabled 等状态，不得用样式掩盖必要操作反馈。

**点击置顶。** 核心在鼠标／触控按下、点击、键盘聚焦及程序打开卡片时标记 `data-前置`；组内条目连同所属盒一起前置。当前页面按导航保留最近操作对象，重绘及切主题后恢复，不写布局或修改 DOM 顺序。`基础.css` 为普通分组建立层级 0，前置的普通盒／卡／步骤使用 30；`.聚起` 和 `.展开` 排除在此规则外，继续使用阅读层级。主题不得用普通卡片层级覆盖此前置行为。

### 核心引用的 CSS 变量

核心自己输出的 SVG 引用下列变量，取值由主题决定，**主题应当在自己的样式里定义它们**。核心已写了 `#888` 兜底，漏定义不会让元素消失，但会退成中性灰，和主题配色脱节。

| 变量 | 核心在哪用 | 漏定义的后果 |
|---|---|---|
| `--线` | 路线流程边 `path.边` 的 stroke | 连线退成中性灰 |
| `--主` | 流程边终点圆点的 fill | 端点退成中性灰 |
| `--好` | 拖拽连线时临时虚线的 stroke | 临时线退成中性灰 |

主题也可以不用这些变量，直接写 CSS 规则给 `path.边`、`#线 circle` 设色——CSS 规则优先于核心写的属性值，矢量和霓虹就是这么做的。

核心反过来提供下列数据，主题按需读取，不用也可以：

| 名称 | 核心写在哪 | 含义 |
|---|---|---|
| `--卡色` | `.卡`、`.步` 的行内样式 | 该条目类型的颜色，值来自主题 `色()` 的返回 |
| `--缩` | `<html>` 行内样式 | 当前缩放的无单位数值，可用于语义缩放的字号补偿 |
| `data-标题` | `.步` 的属性 | 步骤标题，可用 `attr()` 在远景层直接显示 |

### 核心生成、模板换不掉的类名

下列类名不经过区域模板，由核心直接输出，**主题必须给出样式**（最低限度可读即可），不能当成某个主题的装饰删掉：

| 类名 | 核心在哪生成 |
|---|---|
| `.空`、`.空.空位` | 视图空态与数据错误提示 |
| `.边`、`.边击` | 流程边的可见路径与加宽点击区 |
| `.步骤标题按钮` | 详情标题里的改名入口 |
| `.步骤标题编辑` 及其 form / input / button | 步骤标题的编辑表单 |
| `.表滚` | Markdown 表格的横向滚动容器 |
| `.读取` | 正文读取中与空正文提示 |
| `.正文`、`.源码` | 文件预览按 Markdown 或源码切换 |
| `.大纲项` | 详情侧栏的正文标题大纲，带 `data-级`，当前项带 `aria-current` |
| `a.双链`、`span.双链.未找到` | 正文（条目详情和文件预览）里的 `[[双链]]`；找得到的是链接，带 `data-关联` 和行内 `--关联色`（目标类型色），点击由核心跳转；找不到的只是文字 |

`.正文` 和 `.读取` 同时出现在现有主题的模板里；换掉模板后这两个名字仍要留样式。
