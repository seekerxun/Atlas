# 视图

Atlas 通过本地 `atlas serve` 提供界面，无安装依赖、无需打包。功能约束见 `规范/主题制作规范.md`，整体设计见 `规范/视图规范.md`。

## 文件职责

| 文件 | 负责什么 |
|---|---|
| `画布.html` | 功能节点与固定资源入口；新增主题无需修改。 |
| `核心.js` | 数据、五个导航的作用、画布状态、选择、搜索、编辑、预览、保存与撤销。 |
| `基础.css` | 全屏画布、坐标原点、基础输入交互及主题选择入口的共同位置。 |
| `主题加载器.js` | 读取主题目录，加载、校验、启用与清理主题。 |
| `主题/目录.json` | 可选主题、各自的深浅外观及默认主题。 |
| `主题/<id>/样式.css` | 该主题的全部外观、字号、尺寸、位置、响应式和 CSS 动效。 |
| `主题/<id>/主题.js` | 该主题的节点布局、阅读区域、展开定位、语义缩放表现和动画。 |
| `主题/<id>/模板.js` | 该主题的区域模板；各主题自行拆分，互不共享实现。 |

这些界面资源从 `/界面/<路径>` 加载，始终来自 Atlas 的 `视图/`，不从当前被管理项目里找。项目数据走 `/数据`，项目文件走 `/文件/`，文本预览走 `/预览/`。因此无常乐园等项目不需要复制 Atlas 的主题文件。

修改前端文件后刷新即可；修改 Python 服务需重启原项目对应的服务。

## 主题如何接入

新增 `主题/<id>/样式.css`、`主题/<id>/主题.js` 和每个外观一张 `主题/<id>/图标-<外观>.svg`，在 `主题/目录.json` 的 `主题` 数组追加 `{"id":"主题目录名","名称":"显示名称","外观":"浅"}`（`外观` 可为 `"浅"`、`"深"` 或深浅两用的 `["浅","深"]`）。`默认` 填已登记的 id；id 使用中文、字母、数字、下划线或短横线。无需修改 HTML 或核心。

脚本使用 ES 模块，提供 `export default function 创建主题(api)`，返回主题对象。核心负责调用，主题不自行请求写盘接口。模块顶层和创建函数只定义对象与方法，不操作页面；页面变更放在装配钩子中。

准确的 API 名称、11 个布局参数、坐标基准、函数签名与返回值、11 个区域模板、核心引用的 CSS 变量和功能连接点，统一见 [主题接口](主题接口.md)。制作主题必须读取该页；它定义接入方式，不规定任何主题的设计。

主题可重写条目／步骤详情、步骤卡、分组头、路线标题／工具、检查、文件候选、未认领和搜索模板。当前静态功能节点及坐标容器仍保留；可用装配钩子移动原节点，不替换核心事件和状态。主题切换入口会记住选择。

## 已有功能

- 导航切换保留缩放和位置；画布全屏，所有界面覆盖在上面。
- 当前导航按项目记在本机，刷新后回到原来的导航。
- 路线图里拖路线标题可以整体移动一条路线，位置和步骤、分组一样存进 `.atlas/布局.json`，可撤销。
- 所有主题的主题选择都是一枚小图标按钮，紧接搜索框、位于重新扫描之前；点开是跟随当前主题配色的面板，每个方案显示主题自带的缩略图标，悬停提示名字和当前方案。
- 主题面板可固定一个方案，也可「跟随系统」：分别指定白天和夜间用哪个方案，系统深浅变化时自动切换并保留画布状态。深浅两用的主题只登记一次，由 `html[data-外观]` 切配色。
- 鼠标连续悬停卡片 250ms 才显示关联高亮，离开或操作时取消等待；键盘聚焦即时反馈，触发时机由核心统一负责。
- 卡片展开时，导航、未认领、角落控件等全部在它后面且不响应鼠标；点展开卡以外的任何地方都会收起它。
- 卡片和步骤可展开、关闭；正文可阅读，关联、属性、资产和原文可访问。
- 步骤标题点击编辑，Enter 保存、Esc 取消；「加一步」直接创建并进入改名，内部 ID 和连线不变。
- 其余需要输入或确认的操作（新路线、改路线名、删除、AI 护栏、加工具／产出、认领分类）都用页内询问框 `#询问`，不弹浏览器对话框；外观和动画由主题决定。
- 文件选择支持 Markdown、HTML、CSS、JS、Python 等；选择时和挂好后均可预览。Markdown 显示正文，代码显示源码；UTF-8 文本上限 1 MB。
- 检查详情显示原因、位置与建议，能定位时提供文档跳转。未认领工具复用检查器判定，产品代码目录不被误报。
- 路线编辑、认领、保存、撤销及修改时间冲突保护由核心和服务端处理。
- 点顶栏的项目名打开项目窗：列出注册表里的项目及其端口、是否在运行，可以打开、从模板新建（通用项目），或按路径打开其他文件夹。每个项目在自己 `.devdock.json` 写定的端口上起画布，在新标签页打开；DevDock 能看到并停止这些服务。
- 任何入口触发的重新扫描期间，`#刷` 带 `data-扫描中`；两个主题都让扫描箭头转一整圈，扫描未完就接着转。

## 现有主题

- **矢量**（默认，深浅两用）：大地色块、简洁几何形。类型用「色相 × 形状」区分，状态用圆的填满程度表示；动画带弹性回弹，卡片展开、检查弹窗和未认领抽屉都用形状补间。新主题的参考实现。
- **霓虹**（深色）：深夜点阵、霓虹描边、流光连线。

两者的阅读面板都是画布宽的 90%、上限 1320px，手机两侧留 8px；缩放到 55% 以下只留标题。这些数值只是各自的设计选择，其他主题可自行改变。调整主题时验证功能，不要求与现有主题像素一致。
