# 视图

Atlas 通过本地 `atlas serve` 提供界面，无安装依赖、无需打包。功能约束见 `规范/主题制作规范.md`，整体设计见 `规范/视图规范.md`。

## 文件职责

| 文件 | 负责什么 |
|---|---|
| `画布.html` | 功能节点与固定资源入口；新增主题无需修改。 |
| `核心.js` | 数据、五个导航的作用、画布状态、选择、搜索、编辑、预览、保存与撤销。 |
| `基础.css` | 全屏画布、坐标原点、基础输入交互。 |
| `主题加载器.js` | 读取主题目录，加载、校验、启用与清理主题。 |
| `主题/目录.json` | 可选主题及默认主题。 |
| `主题/石墨/样式.css` | 石墨的全部外观、字号、尺寸、位置、响应式和 CSS 动效。 |
| `主题/石墨/主题.js` | 石墨的节点布局、模板、阅读区域、展开定位、语义缩放表现和动画。 |

这些界面资源从 `/界面/<路径>` 加载，始终来自 Atlas 的 `视图/`，不从当前被管理项目里找。项目数据走 `/数据`，项目文件走 `/文件/`，文本预览走 `/预览/`。因此无常乐园等项目不需要复制 Atlas 的主题文件。

修改前端文件后刷新即可；修改 Python 服务需重启原项目对应的服务。

## 主题如何接入

新增 `主题/<id>/样式.css` 和 `主题/<id>/主题.js`，在 `主题/目录.json` 的 `主题` 数组追加 `{"id":"主题目录名","名称":"显示名称"}`。`默认` 填已登记的 id；id 使用中文、字母、数字、下划线或短横线。无需修改 HTML 或核心。

脚本使用 ES 模块，提供 `export default function 创建主题(api)`，返回主题对象。核心负责调用，主题不自行请求写盘接口。模块顶层和创建函数只定义对象与方法，不操作页面；页面变更放在装配钩子中。

`api` 提供选择节点、文本转义、图片后缀判断、减少动态效果判断、分组数据、关联高亮更新，以及 `读取状态()`。读取到的项目数据、视图、缩放、位置、布局和展开节点仅供主题呈现使用，不得修改其中的业务数据；位置是副本。

| 主题接口 | 用途 |
|---|---|
| `布局`、`算库布局()`、`算路线布局()` | 节点大小、内边距、初始排列和路线标题／连线出口位置；读取已有位置，不保存布局。 |
| `导航内容(视图们)`、`定位导航()` | 导航模板和选中态表现；保留按钮的 `data-v` 与 `.导航计数`。 |
| `卡html(n)`、`行(...)`、`详情头(...)`、`色(类型)` | 卡片、关系行、标题和类型的呈现。 |
| `阅读区域()`、`定位展开()`、`定位文件预览()` | 可用区域与阅读位置；居中、侧边、大小均由主题决定。 |
| `初始视野()` | 只返回首次加载的 `{缩, 位}` 建议；核心应用，导航切换不会调用。 |
| `缩放外观(缩)` | 当前缩放下的字号、信息密度和状态类。 |
| `卡片过渡()`、`停卡片动效()`、`布置阅读幕()`、`画布入场()` | 过渡、遮罩、入场和动画清理。 |
| `镜头时长`、`镜头缓动(t)` | 主动调整视野时的动画表现；目标状态仍由核心决定。 |
| 可选 `装配界面()`、`装配画布()`、`装配详情(panel)` | 初始化、每次画布绘制和详情创建时重新排列功能节点；不能删除动作、重复 ID 或替换功能实现。 |

功能 DOM 的 ID、路线 `data-id/data-路线/data-步`、条目 `data-路径`、预览 `data-预览` 等是核心与主题的连接点。详情保留标题 `h3`、关闭 `.收起`、正文／编辑入口。可以换排版和装饰，但不要丢掉这些连接点。

主题副作用使用以下接口，卸载时由加载器回收：

| 接口 | 用途 |
|---|---|
| `监听(target,type,fn,options)`、`延时(fn,ms)`、`循环(fn,ms)` | 自动解绑监听、停止计时器。 |
| `动画(el,frames,options)`、`装饰(el,parent)` | 管理 Web Animations 动画与额外节点；装饰默认加入 body。 |
| `移动(el,parent,before)` | 移动功能节点，卸载时恢复原位置。 |
| `样式(el,values)`、`类名(el,name,enabled)` | 设置样式属性（使用 CSS 属性名）或类名，卸载时恢复。 |
| `清理(fn)`、可选主题方法 `卸载()` | 回收其他主题副作用；不得清除核心状态。 |

这些接口管理资源生命周期，不是任意脚本的沙箱；直接使用浏览器 API 的主题必须自行注册对应清理。主题专属状态类和行内样式也必须恢复。

界面中的主题选择器读取目录并记住选择。新主题资源加载成功、接口校验通过后才替换旧主题；加载失败保留原主题，装配失败尝试恢复原主题。切换保留视图、缩放、位置、搜索、展开内容、阅读滚动和步骤标题草稿。当前正式目录只登记石墨。

## 已有功能

- 导航切换保留缩放和位置；画布全屏，所有界面覆盖在上面。
- 卡片和步骤可展开、关闭；正文可阅读，关联、属性、资产和原文可访问。
- 步骤标题点击编辑，Enter 保存、Esc 取消；「加一步」直接创建并进入改名，内部 ID 和连线不变。
- 文件选择支持 Markdown、HTML、CSS、JS、Python 等；选择时和挂好后均可预览。Markdown 显示正文，代码显示源码；UTF-8 文本上限 1 MB。
- 检查详情显示原因、位置与建议，能定位时提供文档跳转。未认领工具复用检查器判定，产品代码目录不被误报。
- 路线编辑、认领、保存、撤销及修改时间冲突保护由核心和服务端处理。

## 当前石墨设计

本次拆分沿用原有外观：顶部悬浮导航、类型色卡片、居中阅读、窄屏单列。阅读面板宽度为画布的 90%、上限 1320px，手机两侧留 8px；展开 260ms、收起 200ms，分组标题在 50% 以下跟随容器缩小。

这些数值只是石墨的设计选择，其他主题可自行改变。调整主题时验证功能，不要求与石墨像素一致。
